### 股票模擬器

使用 UIKit 開發的股票模擬交易 App，提供自選股、模擬買賣、持倉及損益計算等功能。

**使用技術**

* Swift / UIKit
* MVVM
* Swift Concurrency（async/await）
* RESTful API
* FastAPI / Python
* Git / GitHub

**主要功能**

1. 開發自選股管理功能。
2. 開發股票模擬買進與賣出流程。
3. 開發持倉管理及損益計算功能。
4. 使用 async/await 串接後端 API 並處理資料。
5. 使用 Python / FastAPI 建立後端服務，串接外部股票資料 API，提供 iOS App 所需資料。
